# Tool coverage

How each built-in tool runs in the native viewport: its registry key, its
class, whether it is routed to the native renderer, and what its preview
draws with. "Native" means routed, not an exhaustive parity check.

The table is generated by `tools.metal_coverage.table()`;
`tests/test_wgpu_tool_coverage.py` fails when it no longer matches the tool
registry. Regenerate it from that function after adding a tool.
